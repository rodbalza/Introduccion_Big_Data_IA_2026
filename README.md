## 🚀 Cómo utilizar este repositorio

1. Consulta el [calendario](calendario/README.md) para conocer la planificación.
2. Accede al [índice de clases](clases/README.md) y abre la sesión correspondiente.
3. Cuando la sesión incluya actividades prácticas, visita los [laboratorios](laboratorios/README.md).
4. Vuelve a consultar los materiales para repasar: **se irán completando y actualizando durante el curso**.

> **Nota:** algunas clases pueden aparecer inicialmente solo con el título o el esquema de la sesión. Los contenidos se incorporarán progresivamente a medida que avance el curso.

## 📘 Temas del curso

Durante las sesiones trabajaremos conceptos introductorios de **Big Data, ingeniería y análisis de datos, servicios de datos en Azure e inteligencia artificial**, con actividades prácticas relacionadas con los itinerarios DP-900 y AI-901.
