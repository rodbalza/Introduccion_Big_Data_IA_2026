IA generativa: cómo funciona

Rama de la IA que permite a las aplicaciones generar contenido nuevo: diálogos en lenguaje natural, pero también imágenes, vídeo, código y otros formatos.

⌨️
Prompt
Pregunta o instrucción en lenguaje natural
➜
🧠
Modelo de lenguaje
Entrenado con enormes volúmenes de datos; conoce las relaciones semánticas entre palabras
➜
💬
Respuesta generada
Contenido original y con sentido
LLM · modelos de lenguaje grandes
  • Más datos y más variables (parámetros)
  • Potentes y con buena generalización
  • Más costosos de entrenar y utilizar
SLM · modelos de lenguaje pequeños
  • Enfocados en áreas temáticas concretas
  • Fáciles de desplegar en local
  • Ideales para agentes en dispositivos

Agentes de IA: tres elementos clave

Aplicaciones basadas en IA generativa que razonan y generan lenguaje natural, automatizan tareas mediante herramientas y responden al contexto para actuar.

🧠
Modelo de lenguaje
El «cerebro» del agente: comprensión del lenguaje y razonamiento.
📋
Instrucciones
Prompt del sistema que define el rol y el comportamiento: su «descripción del puesto».
🛠️
Herramientas
Lo que usa para interactuar con el mundo:
  • Conocimiento: buscadores, bases de datos
  • Acción: enviar correos, actualizar calendarios, controlar dispositivos

Texto y lenguaje natural (PLN)

El procesamiento de lenguaje natural es la base de los LLM. Las herramientas especializadas de PLN siguen siendo útiles cuando se necesitan resultados predecibles o reglas personalizadas.

🌐
Detección de idioma
Identifica en qué idioma(s) está el texto; suele ser el primer paso del flujo
🏷️
Clasificación de texto
Asigna categorías, incluido el análisis de sentimiento: positivo, negativo o neutro
Escenarios habituales
  • Analizar transcripciones de llamadas y reuniones
  • Evaluar el sentimiento de reseñas y redes sociales
  • Chatbots de preguntas frecuentes con diálogos predecibles
  • Ocultar PII antes de compartir datos para cumplir la normativa
🔑
Términos clave y entidades
Personas, lugares, organizaciones; detección y ocultación de datos personales (PII)
🗜️
Resumen
Reduce el volumen de texto conservando las ideas principales

IA responsable: seis principios

Los filtros de contenido mitigan riesgos, pero una solución responsable aplica estos principios desde la concepción hasta el diseño, la implementación y la operación.

⚖️
Equidad
Minimizar el sesgo en los datos de entrenamiento y probar que el sistema es justo
🛡️
Fiabilidad y seguridad
La IA es probabilística, no infalible: hay que mitigar los riesgos
🔒
Privacidad y seguridad
Proteger los datos y evitar que el modelo revele información privada
♿
Inclusión
Que las soluciones no excluyan a ningún grupo de usuarios
ℹ️
Transparencia
Explicar cómo funciona el sistema y cuáles son sus limitaciones
🏛️
Responsabilidad
Quien desarrolla y distribuye la IA responde de ella: marco de gobernanza

Paso 1 · Tokenización

Los LLM descomponen su vocabulario en tokens: palabras, subpalabras (como «in» en «increíble» o «improbable»), signos de puntuación y secuencias de caracteres frecuentes.

Cada token distinto recibe un identificador entero único. Los LLM actuales manejan vocabularios de cientos de miles de tokens.

«Oí a un perro ladrar fuerte a un gato»
Oí1
a2
un3
perro4
ladrar5
fuerte6
a2
un3
gato7
Los tokens en gris ya tenían ID asignado y se reutilizan. Con más datos se añaden nuevos tokens: «cachorro», «monopatín», «coche»…

Paso 2 · El transformer

Cada token recibe un vector (una lista de números). El transformer convierte esos vectores iniciales en embeddings con características lingüísticas y semánticas según los contextos en que aparece el token.

Tokens + posición
Vectores iniciales aleatorios y codificación posicional (el orden importa)
➜
Codificador
Atención multicabeza + red neuronal totalmente conectada
Crea los embeddings
➜
Embeddings
Vectores con el contexto de cada token
➜
Decodificador
Atención + red feed-forward
Predice el siguiente token
🎯
Atención: examina cada token y pondera cuánto le influyen los tokens que lo rodean. En «Oí a un perro ladrar», «oí» y «perro» pesan más que «a» o «un» para el token «ladrar». La atención multicabeza evalúa varios elementos del vector en paralelo.

Paso 4 · Predecir la respuesta token a token

1
Entrenamiento con atención enmascarada
Solo se tienen en cuenta los tokens anteriores. Como se conoce el siguiente token real, el modelo compara su predicción y ajusta los pesos para reducir el error.
2
Inferencia
Las capas de atención calculan vectores candidatos y la red feed-forward elige el más probable.
3
Repetición
El token predicho se añade a la secuencia y el proceso se repite hasta que el decodificador predice el final.

Prompts: sistema y usuario

Un prompt es la entrada que damos al LLM; el modelo responde con una completion. El modelo responde al prompt de usuario respetando las pautas del prompt del sistema.

⚙️
Prompt del sistema
Define el comportamiento, el tono y las restricciones del modelo. Normalmente lo fija la aplicación.
Ejemplo
«Eres un asistente útil que responde de forma alegre y cercana.»
👤
Prompt de usuario
Pide una respuesta a una pregunta o instrucción concreta. Lo escribe la persona o lo genera la aplicación.
Ejemplo
«Resume las consideraciones clave para adoptar IA generativa del documento adjunto para un directivo. Máximo seis viñetas, tono profesional.»

Sistemas multiagente

En lugar de que un agente lo haga todo, varios agentes especializados colaboran como un equipo humano. Se comunican mediante prompts y usan IA generativa para decidir qué tareas hacen falta y quién las asume.

🔍
Agente de recopilación
Reúne los datos
Lee las incidencias recibidas de clientes
➜
📈
Agente de análisis
Los analiza
Clasifica por urgencia y detecta patrones
➜
⚡
Agente de acción
Actúa
Abre tickets y avisa al equipo responsable
Ejemplo de empresa: gestión de incidencias de clientes. La IA agéntica es el siguiente gran avance en cómo buscamos información y trabajamos.

Ideas clave

  • 🧩
    La IA abarca varias cargas de trabajo: generativa, lenguaje, voz, visión y extracción
  • ⚖️
    La IA responsable se aplica durante todo el ciclo de vida, con seis principios
  • 🧠
    Un LLM predice el siguiente token usando tokens, embeddings y atención
  • ⌨️
    Prompts claros, con contexto, ejemplos y estructura dan mejores resultados
  • 🤖
    Un agente = modelo + instrucciones + herramientas; varios agentes pueden colaborar
